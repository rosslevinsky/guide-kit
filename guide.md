# Welcome

This is the placeholder content shipped with the `guide-template` repo. It exists so the build pipeline has something to render before you replace it with your own guide.

Edit `guide.md` to write your content. Run `make` to render the PDF. Run `make verify` (after Phase 4 of the bootstrap plan is complete) to confirm a rebuilt PDF matches the committed `baseline.pdf`.

See `README.md` and `CLAUDE.md` for the full workflow.
